# Rahil Ehtesham Mehr

Personal academic website of Rahil Ehtesham Mehr, a physics undergraduate at Sharif University of Technology with interests in experimental condensed matter physics, thin films, and two-dimensional materials.

The website brings together research and projects, a CV, and stories from chess and life beyond physics. Built with Jekyll and adapted from Academic Pages, with light and dark themes and GitHub Pages publishing.

## Updating the website

Follow the [complete website guide](docs/EDITING.md): set up your computer, edit the files, preview the result, and publish to GitHub Pages. The guide keeps the whole workflow in one place, with local editing as the default.
